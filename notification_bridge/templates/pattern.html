Как работает Bridge

Какую задачу решает мост

У уведомления есть два независимых свойства: приоритет (3 варианта) и канал (3 варианта). Без паттерна пришлось бы писать класс на каждую пару, то есть 3 × 3 = 9 классов (EmailNormal, SMSEmergency и так далее), а новый канал добавил бы ещё три.

С мостом классов 3 + 3: приоритеты наследуют Notification, каналы наследуют Channel, а связывает их поле self.channel. Новый канал или приоритет добавляется одним классом и одной строкой в реестре.

Проверьте на своём тексте

{% for c in channels %}{% endfor %} {% for row in matrix %} {% for cell in row %} {% endfor %} {% endfor %}
{{ c }}
{{ priorities[loop.index0] }}
{{ cell.payload }}

Где это в коде

Файл patterns/bridge.py: абстракция Notification с наследниками по приоритетам, реализация Channel с наследниками по каналам, функция create_notification() собирает нужную пару. В app.py она вызывается на странице уведомления и на этой странице.
